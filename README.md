# Задание на отбор, №4 Проников Артём

В рамках этого задания была написана имплементация приложения симуляции экспедиции по шахте. API приложения принимает произвольный алгоритм, по которому бригада шахтёров взаимодействует с интерактивным миром. По окончанию работы алгоритма выводится полная история симуляции, а также её результат. Алгоритм ограничивается по числу шагов, корректность проверяется на этапе выполнения кодом возврата `forbidden`. Проект написан на языке `C++23` с использованием инструмента `CMake`

## Компиляция и запуск

На вход исполняемому файлу с алгоритмом подаётся путь до файла планировки шахты. Алгоритму на старте неизвестны состояния проходов, лишь вероятности их исправности. В случае некорректного формата входного файла поведение не гарантируется, дополнительными проверками в модуле `io` можно создать гарантии, но это заняло бы избыточное количество времени. Парсинг производится по токенам разделённым пробельными символами.

Компиляция происходит с помощью `CMake`:

```bash
mkdir build
cd build
cmake -S .. -B .
cmake --build .
```

Исполняемый файл окажется в директории `bin/`, запуск с первым параметром путь до файла, второй сид генерации шахты

## Структура проекта

Точка входа в приложение --- файл `main.cpp` в `src/`

В `core/` находятся основные сущности программы, используемые во всех модулях. В `comm/` протоколы коммуникации алгоритма и мира, в `expedition` мир, в `algo` конкретный алгоритм. Модуль `io` используется для парсинга и форматирования в `main.cpp`

## Описание алгоритма

Поскольку каждый переход и разведка не уменьшают выгоду, по компоненте связности включающей вход можно собрать все ресурсы со смежных комнат. Делается `dfs`. Далее истинный правильный ответ найти на практике невозможно, поскольку необходимо посчитать матожидание выгоды по неразведанному графу, через формулу полной вероятности получится полный перебор $2^n$. Поэтому приближаем матожидание по ЗБЧ семплированием. После этого получается конкретная карта шахты состоящая из разведанного и случайно сгенерированного но неразведанного. В целом эту задачу можно свести к NP-трудной задача, поэтому производится семплирование и приближение матожидания по ЗБЧ. Расчищается лучший обвал с наибольшей средней ценностью за ним. Оценка смотрит на одну расчистку вперёд.
