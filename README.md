# Задание на отбор, №4 Проников Артём

В рамках этого задания была написана имплементация приложения симуляции экспедиции по шахте. API приложения принимает произвольный алгоритм, по которому бригада шахтёров взаимодействует с интерактивным миром. По окончанию работы алгоритма выводится полная история симуляции, а также её результат. Алгоритм ограничивается по числу шагов, корректность проверяется на этапе компиляции. Проект написан на языке `C++23` с использованием инструмента `CMake`

## Компиляция и запуск

На вход исполняемому файлу с алгоритмом подаётся путь до файла планировки шахты. Алгоритму на старте неизвестны состояния проходов, лишь вероятности их исправности. В случае некорректного формата входного файла поведение не гарантируется, дополнительными проверками в модуле `io` можно создать гарантии, но это заняло бы избыточное количество времени. Парсинг производится построчно по первому ключевому слову.
